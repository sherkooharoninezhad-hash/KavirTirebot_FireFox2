# ساخت نسخه مستقل ویندوز ربات کویر تایر

این مخزن با GitHub Actions یک نسخه ویندوزی می‌سازد که Python و Playwright لازم نیست روی سیستم کاربر نصب باشند.
Firefox مخصوص Playwright نیز هنگام ساخت بسته دانلود و کنار فایل اجرایی قرار می‌گیرد؛ بنابراین در سیستم کاربر نصب جداگانه Firefox انجام نمی‌شود.

## ساخت فایل اجرایی
1. همه محتویات این پوشه را در مخزن GitHub خود بارگذاری کنید.
2. از زبانه Actions، گردش کار **Build Windows EXE with Firefox** را انتخاب کنید.
3. روی **Run workflow** کلیک کنید (یا با push به شاخه main/master خودکار اجرا می‌شود).
4. پس از موفقیت، در پایین صفحه اجرای Workflow، بخش Artifacts را باز کنید.
5. فایل `KavirTireBot-Windows-EXE` را دانلود و از حالت ZIP خارج کنید.
6. برنامه را با دوبار کلیک روی `KavirTireBot.exe` اجرا کنید.

## نکته
- این محیط لینوکسی نمی‌تواند فایل EXE ویندوزی را به‌صورت محلی بسازد؛ ساخت واقعی EXE توسط GitHub Actions روی Windows انجام می‌شود.
- کل پوشه `KavirTireBot` را نگه دارید؛ فقط EXE را جدا نکنید، چون پوشه `pw-browsers` شامل Firefox است.
- `__pycache__`، `.venv` و خروجی‌های قدیمی build لازم نیستند.
